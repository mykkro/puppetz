# models/: Puppetz characters

One folder per character:

| File | |
|---|---|
| `<id>/<id>.json` | the character description (source of truth, edit this) |
| `<id>/<id>.glb` | baked glTF binary, generated by `npm run build:glb` (don't edit) |
| [index.json](index.json) | list of characters used by the viewers and the GLB builder |
| [character.schema.json](character.schema.json) | JSON Schema for the character files |

Current characters:

| id | | clips |
|---|---|---|
| [shark](shark/shark.json) | the Puppetz star: a shark standing like a dinosaur, hinged jaw, crescent tail fin, fish prop | idle, walk, **eat**, blink |
| [alzak](alzak/alzak.json) | green alien in a tin can (inspired by the Alza.cz mascot) | idle, walk, blink |
| [chicken](chicken/chicken.json) | cartoon chicken with crossed wings (inspired by *Moorhuhn*) | idle, walk, blink |
